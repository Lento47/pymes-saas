# Proceso de Onboarding de Clientes en PymeHub

## 1. Proposito

Este procedimiento estandariza el alta de nuevos clientes para que PymeHub inicie con configuracion minima suficiente, aceptacion documental, responsabilidades claras y expectativa correcta sobre el servicio contratado.

## 2. Entradas del proceso

El onboarding debe iniciarse solo cuando exista, como minimo:

- decision comercial o contratacion cerrada;
- cliente identificado;
- plan o alcance definido;
- responsable del workspace por parte del cliente.

## 3. Flujo operativo

1. Confirmar plan contratado, identidad del cliente y responsable del workspace.
2. Crear el workspace inicial y el usuario administrador (`OWNER`).
3. Registrar aceptacion de terminos, privacidad y documentos comerciales aplicables.
4. Configurar datos base, departamentos y usuarios iniciales segun alcance.
5. Definir canales de entrada habilitados.
6. Configurar etiquetas, categorias o parametros operativos minimos.
7. Habilitar importacion inicial si aplica.
8. Explicar limites del plan, roles, soporte, IA, OCR y politicas de uso.
9. Confirmar puntos de contacto de soporte, privacidad y facturacion.

## 4. Salidas del proceso

El onboarding se considera cerrado cuando:

- el workspace esta activo;
- el cliente cuenta con acceso administrador;
- los documentos aplicables fueron aceptados o referenciados;
- el cliente conoce canales de soporte y reglas basicas del servicio.

## 5. Evidencia minima

- fecha de alta;
- responsable del cliente;
- plan;
- documentos aceptados y version;
- checklist de activacion completado;
- observaciones relevantes de configuracion o limitaciones.
