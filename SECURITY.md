# Security Policy

## Supported Versions

PymesHub es una plataforma SaaS — solo la versión actual en producción recibe
actualizaciones de seguridad. No mantenemos versiones anteriores.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Si encontrás una vulnerabilidad de seguridad, **no la reportes públicamente** en
issues ni pull requests. Reportala de forma privada para que podamos
solucionarla antes de que sea explotada.

**Dónde reportar:**  
Enviá un email a **security@pymeshub.com** con los detalles.

**Qué incluir:**
- Descripción clara del problema
- Pasos para reproducirlo
- Versión afectada
- Impacto potencial

**Qué esperar:**
- Acuse de recibo en **48 horas** hábiles
- Actualización sobre el estado en un máximo de **7 días**
- Si el reporte es aceptado, trabajaremos en un fix y te mantendremos al tanto
- Si es declinado, te explicaremos por qué
- Una vez resuelto, publicaremos un advisory y daremos crédito al reportante
  (a menos que prefieras anonimato)
