# Checklist de Cumplimiento Pre-Lanzamiento para PymesHub en Costa Rica

## 1. Proposito

Este checklist funciona como criterio formal de salida a operacion comercial. Ninguna salida deberia considerarse ordenada si este documento no puede completarse con evidencia suficiente o con una decision consciente de aceptacion de riesgo.

## 2. Reglas de uso

- Cada item debe tener estado: `Completo`, `En curso`, `Pendiente`, `No aplica`.
- Todo item marcado como `Completo` debe tener evidencia o referencia.
- Los items `Pendiente` con impacto alto deben escalarse antes del lanzamiento.
- Debe existir un responsable interno del cierre del checklist.

## 4. Criterio de aprobacion

El lanzamiento deberia aprobarse cuando:

- no existan pendientes criticos sin mitigacion;
- los documentos externos esenciales esten listos;
- el producto tenga, al menos, un plan claro para aceptacion legal, privacidad, auditoria y multi-tenancy;
- el riesgo residual pendiente haya sido aceptado expresamente.
