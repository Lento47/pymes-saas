# Uso de Ubicación en Entregas

Documento público canónico: [`/legal/location-use`](https://pymeshub.lat/legal/location-use).

PymesHub solicita ubicación precisa y en segundo plano únicamente cuando un repartidor comienza una entrega asignada. La ubicación se limita a los participantes autenticados del pedido y el seguimiento termina al completar, cancelar o reasignar la entrega, al cerrar sesión o al retirar el permiso.

La aplicación informa este uso antes de pedir permiso. Android muestra una notificación persistente durante el seguimiento activo. La aplicación puede enviar hora de medición, precisión, rumbo y velocidad, con intervalos adaptados al movimiento y limitación del servidor.

Para ejercer derechos o consultar el tratamiento, escribe a `privacidad@pymeshub.lat`.
