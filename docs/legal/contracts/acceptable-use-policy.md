# Politica de Uso Aceptable de PymeHub

## Proposito

Esta politica define usos prohibidos y controles minimos para proteger PymeHub, a otros clientes, a terceros y a `[NOMBRE_EMPRESA]`. Aplica a todo usuario, cliente, proveedor o integracion que utilice el servicio.

## Usos permitidos

PymeHub debe usarse para operaciones legitimas de negocio relacionadas con gestion de conversaciones, clientes, tareas, documentos, automatizaciones y reportes internos del cliente.

## Usos prohibidos

Se prohibe usar PymeHub para:

- spam, envio masivo no consentido o campañas abusivas;
- fraude, suplantacion, phishing, estafas o engaño comercial;
- distribuir malware, enlaces maliciosos o archivos nocivos;
- scraping no autorizado del servicio, APIs o datos de terceros;
- realizar pruebas de intrusion no autorizadas;
- intentar acceder, inferir o exfiltrar datos de otros tenants;
- saturar el inbox, la API o los workers con trafico abusivo;
- cargar documentos ilicitos, robados, falsificados o que infrinjan derechos de terceros;
- almacenar credenciales de terceros en campos o adjuntos no previstos;
- usar automatizaciones para acciones contrarias a la ley o al consentimiento del destinatario;
- usar OCR o IA para decisiones automaticas sensibles sin validacion humana adecuada;
- revender el servicio o exponerlo a terceros sin autorizacion escrita.

## Consecuencias

`[NOMBRE_EMPRESA]` puede investigar, limitar, suspender o terminar accesos cuando detecte uso prohibido o riesgo grave. Tambien podra preservar evidencias, bloquear contenido o cooperar con autoridades cuando sea legalmente necesario.

## Cooperacion del cliente

El cliente debe colaborar con investigaciones razonables, corregir configuraciones inseguras, desactivar usuarios comprometidos y asumir responsabilidad por las acciones de sus usuarios, agentes, integradores o contractors dentro de su workspace.
