# Enterprise Self-Hosted Service Model

Documento operativo para acompañar el contrato enterprise self-hosted.

## Cobertura mínima

- licencia de uso self-hosted por cliente / tenant
- límites de ambientes y usuarios según acuerdo comercial
- responsabilidades sobre infraestructura, backups y seguridad
- ventanas de mantenimiento y proceso de upgrade
- compatibilidad de versiones entre API, web, base de datos y desktop opcional
- reglas de acceso remoto para soporte
- residencia y custodia de datos

## Diferencia frente a SaaS

En `cloud`, PymeHub opera la plataforma.

En `enterprise`, PymeHub entrega software y soporte bajo condiciones específicas, pero la operación puede quedar en el cliente o ser compartida por servicios profesionales.
