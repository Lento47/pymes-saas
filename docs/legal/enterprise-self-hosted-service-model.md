# Enterprise Windows Native Service Model

Documento operativo para acompañar el contrato enterprise de servidor local Windows.

## Cobertura mínima

- licencia de uso local por cliente / tenant
- límites de ambientes y usuarios según acuerdo comercial
- responsabilidades sobre infraestructura Windows, backups y seguridad
- ventanas de mantenimiento y proceso de upgrade
- compatibilidad de versiones entre API, web, PostgreSQL, storage local y desktop opcional
- reglas de acceso remoto para soporte
- residencia y custodia de datos

## Diferencia frente a SaaS

En `cloud`, PymesHub opera la plataforma.

En `enterprise`, PymesHub entrega software y soporte bajo condiciones específicas, pero la operación puede quedar en el cliente o ser compartida por servicios profesionales sobre un servidor Windows local.
