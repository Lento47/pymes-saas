# PymesHub iOS App

Carpeta local de planificacion para una futura app nativa de PymesHub en iOS.

## Archivos

- `product-plan.md`: alcance funcional, fases de MVP y decisiones abiertas.
- `technical-architecture.md`: arquitectura SwiftUI, autenticacion, API, seguridad y datos.
- `github-roadmap.md`: propuesta de milestones, issues y flujo de ramas/PRs para GitHub.

## Estado

El scaffold local de la app ya existe en `apps/ios/PymesHub`.

No modifica API/web, no cambia workflows y no toca despliegues de `main-api` o `main-web`.

## Siguiente paso recomendado

Abrir `apps/ios/PymesHub/PymesHub.xcodeproj` en Xcode sobre macOS, configurar signing y ejecutar el build contra un simulador iOS 17+.
