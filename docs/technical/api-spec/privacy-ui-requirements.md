# Requisitos de UI de Privacidad para PymeHub

## 1. Proposito

Esta especificacion define los avisos, enlaces, disclosures y patrones minimos de interfaz que PymeHub debe mostrar para sostener transparencia de privacidad y coherencia con su documentacion legal.

## 2. Flujos cubiertos

- registro de cuenta y creacion de workspace;
- formularios de contacto, demo o lista de espera;
- carga de documentos;
- importacion de contactos;
- configuracion de canales de comunicacion;
- configuracion o uso de funciones de IA;
- flujos de soporte con carga de evidencias o archivos.

## 3. Reglas obligatorias

- Los enlaces a Terminos y Privacidad deben ser visibles en flujos criticos.
- Los checkboxes de aceptacion no deben venir premarcados.
- Cuando exista procesamiento por IA u OCR, la UI debe explicarlo en lenguaje claro.
- Si existe configuracion de retencion, exportacion o borrado, debe ser accesible a administradores autorizados.

## 4. Criterios de evidencia

La experiencia de UI debe permitir demostrar, al menos:

- que el usuario tuvo acceso a la politica relevante;
- que el disclosure fue visible en el flujo correspondiente;
- que la aceptacion, si aplica, quedo registrada.
