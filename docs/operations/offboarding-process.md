# Proceso de Offboarding de Clientes en PymeHub

## 1. Proposito

Este procedimiento gestiona la salida ordenada de un cliente de PymeHub, asegurando control sobre cancelacion, exportacion, cierre de acceso, retencion y evidencias necesarias.

## 2. Entradas del proceso

El offboarding puede iniciarse por:

- cancelacion solicitada por el cliente;
- no renovacion;
- terminacion por incumplimiento;
- cierre forzado por riesgo o causa legal.

## 3. Flujo operativo

1. Recibir solicitud o confirmar causal de terminacion.
2. Verificar identidad y facultad del solicitante.
3. Revisar saldos, periodo vigente y restricciones operativas.
4. Definir si procede exportacion de datos y en que formato.
5. Aplicar periodo de gracia si corresponde.
6. Ejecutar cierre funcional del workspace.
7. Programar borrado o anonimización segun politica de retencion.
8. Registrar cierre final y evidencia de acciones ejecutadas.

## 4. Controles obligatorios

- La exportacion no debe comprometer datos de otros tenants.
- El borrado no debe impedir conservar evidencia minima de facturacion o seguridad.
- Los backups residuales deben seguir su ciclo tecnico normal.
- Si existe impago o riesgo, el acceso puede restringirse antes del cierre total.

## 5. Salidas del proceso

El offboarding se considera cerrado cuando:

- el acceso del cliente ha sido desactivado o restringido segun corresponda;
- la exportacion fue entregada o cerrada documentalmente;
- se definio el tratamiento posterior de los datos;
- quedaron registradas las evidencias del cierre.
