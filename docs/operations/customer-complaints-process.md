# Proceso de Reclamos y Quejas de Clientes de PymesHub

## 1. Proposito

Este procedimiento define como PymesHub recibe, clasifica, investiga y cierra reclamos de clientes de naturaleza comercial, operativa, de soporte, privacidad, seguridad o contractual.

## 2. Flujo

1. Recepcion del reclamo por canal autorizado.
2. Registro con fecha, cliente, categoria y responsable.
3. Clasificacion: comercial, soporte, facturacion, privacidad, seguridad o contractual.
4. Respuesta inicial con numero de seguimiento o confirmacion equivalente.
5. Escalamiento interno cuando el caso lo requiera.
6. Resolucion o propuesta de salida.
7. Cierre con evidencia de respuesta.

## 3. Escalamiento

Se debe escalar cuando:

- involucre datos personales;
- exista disputa de cobro;
- sugiera incidente de seguridad;
- exista riesgo contractual o reputacional alto.

## 4. Evidencia minima

- descripcion del reclamo;
- fecha de recepcion;
- area responsable;
- acciones tomadas;
- fecha de cierre;
- si hubo compensacion, nota de credito o ajuste.
